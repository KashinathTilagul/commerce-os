# Global Skills Directory

Skills in EKVAAR OS are stored globally rather than being attached to a single agent. This allows multiple Digital Employees to reference, utilize, and suggest improvements to the same core knowledge bases, frameworks, and playbooks.

## Structure
Every skill is a markdown file (or a directory for complex skills) containing:
- Knowledge & Domain Expertise
- Frameworks
- Playbooks
- Best Practices

When an employee needs a skill, it is linked to their profile, granting them access to this shared knowledge.
