# EKVAAR OS V2 — APPLICATIONS & FEATURES MANUAL

This manual details every application, utility, and user-facing feature embedded in EKVAAR OS V2, mapped to the system's Tahoe Design System guidelines.

---

## 1. Primary Operating Workspaces

These workspaces handle the principal analytical and executive business logic:

### 1. Mission Control (`mission_control`)
- **Purpose**: High-altitude visualization of the entire business roadmap.
- **Visuals**: Spatially projects the active execution chain (`Missions` → `Initiatives` -> `Projects` -> `Tasks`). 
- **Interactive Nodes**: Blocked nodes glow red, indicating pending sub-agent blockages or unresolved dependencies. Founders can click nodes to immediately authorize decisions or re-route.

### 2. Knowledge Vault (`krishna_vault`)
- **Purpose**: Visual exploration of institutional memory.
- **Features**: Interactive graph visualizer displaying associations between approved business outputs, decisions, and knowledge metrics.
- **Search**: Integrated semantic context search with sidebar categories.

### 3. Intelligence Center (`intelligence_workspace`)
- **Purpose**: Operational feed mapping all real-time system alerts.
- **Tabs**: Categorized into `All`, `Decision`, `Risk`, `Opportunity`, and `Trend`.
- **Feed Details**: Automatically parses variant inventory violations, customer spent spikes, and external market shifts, presenting actionable recommendations.

### 4. Execution Workspace (`exec_workspace`)
- **Purpose**: Tracks active task queues and processes.
- **Features**: Kanban board-style grids showing pending, executing, and completed workloads, displaying CPU utilization, and logs generated by AI operators.

### 5. Automation Center (`automation_workspace`)
- **Purpose**: Observability dashboard monitoring automatic routines.
- **Features**: Real-time diagnostic feeds, performance graphs showing script execution latency, and enable/disable triggers for active cron jobs.

### 6. Communications Hub (`comm_workspace`)
- **Purpose**: Unified workspace for corporate communication threads (Email, SMS, Slack integrations).
- **Features**: Split pane showing conversation queues, contact avatars, and text body.

### 7. Agent Network (`agents`)
- **Purpose**: Swarm interface showing active AI assistants.
- **Telemetry**: Displays worker capability parameters, memory load, and current execution queue.

## 2. Core Desktop Utilities

These standard applications provide utility and productivity tools:

- **Hermes Command Center (`hermes`)**: A dedicated chat application running on the FastAPI agent core. Backed by Groq/OpenRouter fallback routing, it features formatted text, lists, and monospace code layouts.
- **Founder Brain (`notes`)**: Persistent draft notepad integrated into the SQLite database.
- **File Manager / Finder (`files`)**: File searcher that indexes content across local databases and project assets.
- **Operations Calendar (`calendar`)**: Maps start/end schedules for events.
- **Communications Client (`mail` & `contacts`)**: Visual layouts for mail grids and detailed profile cards.
- **Media Tools (`music` & `video_player` & `photos`)**: Implements QuickTime style overlays, image galleries, and custom playlist players.
- **General Utilities**: `Terminal` (simulates prompt loops), `Activity Monitor` (shows running daemon loads), `Clock`, `Weather`, `Dictionary`, and a native `Poker` felt table.

---

## 3. Global Control Panels

- **Top Bar**: macOS Sonoma style 28px glassmorphic tray displaying date/time, Wifi/Battery status, and toggles for active control center panels.
- **Control Center Popover**: Brightness control sliders, Wifi/Bluetooth/AirDrop quick toggles, and live check indicators.
- **Launchpad**: Overlay displaying responsive grid layouts of all registered apps with custom icons.
- **System Settings**: Configures theme parameters, safe mode overrides, and SQLite database factory resets.
- **Recovery Mode**: Red alert interface that halts OS boots to isolate unhandled React components or parse exceptions.
