# Legal & Compliance Data Model

## Contract Object
- Contract ID
- Counterparty
- Value
- Risk Level
- Obligations
- Status (Draft, Approved, Executed, Expired)

## Risk Object
- Risk ID
- Category (Legal, Regulatory, Financial, Reputational, Operational)
- Probability
- Impact
- Mitigation Plan

## Compliance Event
- Event ID
- Regulation
- Status
- Deadline
- Responsible Party
