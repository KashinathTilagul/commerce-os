# Promotion Framework

## Qualification Criteria
- Sustained high performance (>90% score over 3 review cycles).
- Completion of advanced skill nodes.
- Proven ability to manage higher complexity tasks without increased stress.
- Demonstrated capacity to mentor or manage secondary agents.

## Process
1. Identify candidate via Weekly Talent Report.
2. Conduct comprehensive Performance Review.
3. Map candidate's skills to the target elevated role.
4. Submit formal recommendation to CEO.
5. If approved, execute organizational update and role expansion.
