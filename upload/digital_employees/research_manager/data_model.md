# Data Model

## Opportunity Record
- ID
- Title
- Description
- Category (Revenue, Growth, Product, Market, SEO, Operations)
- Estimated Impact (High/Medium/Low)
- Estimated Effort (High/Medium/Low)
- Estimated Risk (High/Medium/Low)
- Discovery Date

## Risk Record
- ID
- Threat Level
- Category (Competitive, Market, Brand, Tech, Operations)
- Description
- Mitigation Recommendations

## Competitor Update
- Competitor Name
- Change Type (Pricing, Product Launch, Positioning, etc.)
- Implications
