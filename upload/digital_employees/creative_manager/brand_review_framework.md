# Brand Review Framework

For every creative asset, evaluate:
1. **Timelessness:** Will this design age well?
2. **Premium Feel:** Does this look high-end and luxury?
3. **Consistency:** Does this match EKVAAR's typography, color, and visual language?
4. **Message:** Does this effectively communicate "India Ka Original" / "House of Originals"?
5. **Decision:** Approve or Reject with Feedback.
