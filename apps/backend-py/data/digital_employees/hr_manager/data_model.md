# HR & Talent Data Model

## Employee Object
- Employee ID
- Role & Department
- Skill Profile (Current vs Target)
- Performance Score
- Stress Level (%)
- Learning Path ID

## Performance Review Object
- Review ID
- Employee ID
- Period
- Strengths / Weaknesses
- Recommended Actions

## Skill Node Object
- Skill ID
- Category
- Proficiency Level Required
- Current Proficiency Level
